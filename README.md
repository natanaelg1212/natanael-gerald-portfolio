# Natanael Gerald — Designer Portfolio

Static portfolio website, ready for GitHub Pages, Vercel, or Netlify.

## Run locally
Open `index.html` in a modern browser, or use a local static server:
`python -m http.server 8000`

Then visit `http://localhost:8000`.

## Deploy to Vercel
1. Upload this folder to a GitHub repository.
2. Import the repository in Vercel.
3. Framework preset: Other.
4. Build command: leave empty.
5. Output directory: `.`

No build step or npm install is required.

## Included
- White/off-white editorial portfolio design.
- Your provided portrait.
- CV PDF and original portfolio PDF.
- Portfolio images extracted from the supplied portfolio PDF.
- Interactive project case studies.
- WebGL liquid image distortion reacting to mouse movement.
- Responsive mobile layout.
- Archive filters and image lightbox.

## Editing
Project/case-study data is in `app.js`.
Portfolio images are in `assets/`.
